执行摘要
01 / 11
CrewAI
偏企业代理工作流平台
公开展示 Free 与 Enterprise Custom 两层；同时覆盖 SaaS 与自托管，强调治理、支持与规模化运行。
LangGraph / LangSmith
偏生产部署基础设施
核心价值在 durable execution、状态管理、长任务运行与多代理生产部署，价格金额未公开，但计划门槛清晰。
AutoGen Studio
偏低代码开发工具 / 研究生态入口
独立商业化信息有限；微软更成熟的企业化与商业化能力主要体现在 Agent Framework 与 Copilot Studio。

最重要发现

  • CrewAI 是三者中公开定价结构最直观者：Free 免费，企业版为 Custom 定制定价。
  • LangGraph Platform 在 2025 年后官方名称已转为 LangSmith Deployment，应视为同一条产品演进线。
  • AutoGen Studio 未检索到独立官方价格与客户名单，不能用 Copilot Studio 价格替代其价格。
  • 三者都面向 Agent 场景，但主抓层次不同：工作流平台、部署运行时、低代码构建入口。

管理层判断

  • 若优先考虑 企业治理 + 私有化 + 交付支持，CrewAI 信息最完整。
  • 若重点在 长任务、有状态、生产运行时基础设施，LangSmith Deployment 更贴近平台底座。
  • 若当前处于 研究、原型、低代码试验 阶段，AutoGen Studio 更像前端入口；进入正式采购常要看微软企业产品线。
结论不是“谁最好”，而是“谁更适合所处阶段与治理要求”。
结论严格基于已检索到的官方材料，不补充未确认信息

CrewAI 拆解：平台能力、部署与定价策略
04 / 11

产品功能

  • AMP 官方定位：Deploy / Monitor / Scale agent workflows
  • 可视化编辑器、AI copilot、GitHub 集成
  • Tracing、Logs、OpenTelemetry、使用仪表盘、性能指标
  • Guardrails、LLM testing、AI agent training、Hallucination scores
  • Human-in-the-loop、Workflow chat UI、Slack/Teams 接入
  • SSO、RBAC、Deployment history、Automatic scaling

部署形态

  • AMP（SaaS）：零安装、托管基础设施、自动更新维护、无代码/低代码构建
  • Factory（Self-hosted）：部署到客户基础设施、Kubernetes、VPC、云数据库、对象存储
  • 支持多种 ingress、密钥管理、TLS、SSO、HA、外部数据库与对象存储
治理导向较强，适合对数据边界和网络控制敏感的组织。

定价策略

  • Basic Free：免费
  • Free 明确包含：Visual editor、AI copilot、GitHub integration、每月 50 次 workflow executions
  • Enterprise Custom：官方未公开具体金额
  • 企业版包含：私有基础设施、现场支持与培训、每月 50 小时开发支持、执行能力按工作流匹配、弹性 overage

目标客户

  • 从试点走向规模化的企业团队
  • 重视私有部署、权限治理、组织支持服务的客户
  • 需要将 agent workflow 纳入生产运营、监控与合规体系的组织
CrewAI 在已知资料中最像“可直接采购的企业平台套餐”，而不只是开发框架。
客户覆盖的公开表述仅见“Used by 63% of the Fortune 500”，未见更细客户名单
LangGraph Platform / LangSmith Deployment 拆解
05 / 11

名称演进与定位

  • LangGraph Platform 已于 2025 年 10 月更名为 LangSmith Deployment
  • 原部署、API、工作流、定价和合同保持不变
  • 定位：面向生产环境的 AI Agent 部署与运行基础设施
  • 与 LangGraph 关系：LangGraph 负责构建；LangSmith Deployment 负责生产部署与管理

核心功能

  • durable execution、state/task management
  • human-in-the-loop、background tasks、memory、threading
  • multi-agent coordination、fault tolerance、horizontal scaling
  • registry、versioning、instant rollback
  • 约 30+ API endpoints、协议端点、Studio 调试

部署与定价策略

  • 2026 文档：Cloud / Self-hosted / Standalone server
  • 历史资料：Cloud SaaS / Hybrid(BYOC) / Fully Self-Hosted / Self-Hosted Lite
  • 未检索到公开价格金额
  • Cloud：要求 Plus plan 或以上
  • Self-hosted / Hybrid：面向 Enterprise plan
  • 早期 Self-Hosted Lite：曾给出 免费节点额度

目标客户

  • 需要在生产环境运行长任务、有状态 agent 的工程团队
  • 关注任务持久化、并发、扩缩容、审计与版本回滚的企业
  • 已有开发能力，希望把“运行时基础设施”做厚的组织
相比 CrewAI，LangSmith Deployment 更强调“生产运行底座”，而非完整业务工作流平台包装。
可确认计划门槛，但无法从已知资料给出价格金额或典型合同规模
Microsoft AutoGen Studio 拆解：能力入口与企业化边界
06 / 11

AutoGen Studio 产品功能

  • 官方定位：低代码多智能体开发工具
  • 拖放式多智能体构建器
  • 实时更新与执行过程反馈
  • 流程可视化
  • 执行控制
  • 组件画廊 / 组件复用

企业化延伸说明

  • 微软 2026 年更强的企业能力主要体现在 Agent Framework 与 Copilot Studio
  • 包括：状态管理、工作流、中间件、可观测性、检查点恢复
  • 以及：A2A、MCP、治理、分析、代理标识、异步响应、合规中心能力
即：AutoGen Studio 更像生态入口；企业级运行与治理更多依托微软其他产品线。

定价策略

  • 未检索到 AutoGen Studio 独立官方价格
  • 可确认的商业化信息来自 Copilot Studio / Microsoft 365 Copilot
  • M365 Copilot：232元 / 用户 / 月（按年付费）
  • Copilot Studio：支持容量包、Copilot 积分与按量模式
不能将 Copilot Studio 或 M365 Copilot 的价格直接等同为 AutoGen Studio 价格。

目标客户

  • 开发者、研究团队、需要快速构建多智能体原型的组织
  • 适合探索、试验、交互式搭建
  • 若进入企业级治理、正式采购与渠道发布，多半转向 Agent Framework / Copilot Studio 路径

选型建议
10 / 11

1. 想快速做业务工作流并兼顾治理的企业

优先看 CrewAI
  • 已有明确 Free→Enterprise 进阶路径
  • 工作流、可视化、治理、支持服务相对一体化
  • 同时支持 SaaS 与自托管，便于按合规要求选路

2. 已有较强工程能力，关注生产运行时与状态编排

优先看 LangSmith Deployment
  • 核心优势在 durable execution、state/task management
  • 适合将 agent 当成生产系统来运营
  • 尤其适合长任务、多线程、多代理与版本治理场景

3. 先做研究和原型，后续再转企业平台的团队

优先看 AutoGen Studio
  • 适合低代码原型、多智能体实验与交互探索
  • 若进入大规模治理与正式采购，需同步评估 Agent Framework / Copilot Studio
  • 避免把原型工具直接等同于企业商业平台
推荐的本质：按组织成熟度、工程能力、治理要求选择，而不是按“热度”选择
结论
11 / 11

最终判断

  • CrewAI 更像可直接落地的企业代理工作流平台，公开商业层级最清晰。
  • LangGraph Platform / LangSmith Deployment 更偏生产运行时与部署基础设施，适合工程化要求高的团队。
  • AutoGen Studio 更偏低代码开发入口；微软正式企业能力与商业化重心更多在 Agent Framework / Copilot Studio。
  • 公开资料对 企业报价金额、合同规模、客户名单 普遍有限，管理层应将本报告视为 初筛工具。
  • 正式采购前，仍需与厂商确认：价格、部署边界、SLA、合规能力、支持服务与迁移成本。
